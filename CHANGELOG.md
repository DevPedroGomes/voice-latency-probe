# Changelog

## 0.1.0

- `voice-probe call`: a synthetic caller that speaks in real time and records timings on one clock.
- `voice-probe analyze`: voice to voice, end of turn, reply, agent and delivery, plus the agent's own number against the caller's.
- `voice-probe compare`: two runs at the median.
- `voice-probe fake-agent`: an agent with known delays, used by CI to check the probe against a real LiveKit server.
